# SK Web Studio

A responsive static website for SK Web Studio.

## Files
- `index.html` — website pages/sections
- `style.css` — design and responsive layout
- `script.js` — mobile menu, year and WhatsApp enquiry form
- `assets/favicon.svg` — favicon

## Before publishing
1. Replace demo portfolio items with your real work.
2. Replace `hello@skwebstudio.in` if you use another email.
3. Buy `skwebstudio.in` from a domain registrar.
4. Deploy these files to your hosting provider.
5. Connect the domain DNS to the hosting provider.
